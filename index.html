유튜브 소리를 화면 녹화로 담아오기

더 간단한 길: 위 음원 검색 탭에서 저작권 프리 곡을 골라 바로 쓰면 화면 녹화가 필요 없습니다. 꼭 유튜브의 특정 곡이어야 할 때만 아래 방법을 쓰세요.

휴대폰 브라우저는 다른 앱의 소리를 직접 받을 수 없습니다. 대신 폰의 화면 녹화 기능으로 유튜브를 재생하며 녹화하면 소리가 담긴 영상 파일이 생깁니다. 그 파일을 아래에 올리면 소리만 뽑아 BGM으로 씁니다. 화면은 버리고 소리만 쓰므로 어떤 화면을 녹화했는지는 상관없습니다.

안드로이드 (갤럭시 기준) ① 화면 위에서 아래로 두 번 내려 빠른 설정을 엽니다
② 화면 녹화 타일이 안 보이면 → 오른쪽 위 연필 모양 버튼 탭 → 아래 ‘사용 가능한 버튼’에서 화면 녹화를 위로 끌어다 놓고 완료
③ 화면 녹화 탭 → 소리 선택창에서 미디어 소리 (마이크 아님) → 녹화 시작 → 3초 뒤 시작
④ 유튜브 앱에서 곡 재생 → 다 흐르면 화면의 정지 버튼 탭
⑤ 갤러리에 저장된 녹화 영상을 아래 버튼으로 선택
깨끗하게 담는 요령 — 녹화 전에 방해 금지를 켜세요(알림음이 섞입니다). 광고가 있으면 광고가 끝나고 곡이 시작된 뒤에 녹화를 시작하고, 유튜브 자동재생은 꺼 두세요.
아이폰 ① 설정 → 제어 센터 → 화면 기록 추가 (한 번만)
② 제어 센터를 열고 화면 기록(동그라미) 버튼 탭 → 3초 후 시작
③ 유튜브 앱에서 곡 재생 → 끝나면 상단 빨간 표시 탭 → 중단
④ 사진 앱에 저장된 영상을 아래 버튼으로 선택
요령 — 녹화 전에 방해 금지를 켜고, 광고가 끝난 뒤 녹화를 시작하세요.
녹화는 2분 안쪽으로 짧게 잡으세요. 파일이 크면 소리를 뽑는 데 오래 걸리고 메모리가 부족할 수 있습니다. 곡의 특정 부분만 쓰려면 다음 단계의 BGM 시작 지점으로 맞추면 됩니다.

유튜브 소리를 BGM으로 (PC)

유튜브 링크를 붙이면 이 화면 안에서 재생되고, 캡처를 시작하면 그 소리가 그대로 녹화 오디오로 들어갑니다. 마이크로 주워담는 게 아니라 브라우저 내부에서 직접 가져오므로 잡음이 없습니다.

  1. 위에 링크를 붙여 불러오기 → 플레이어에서 재생
  2. 아래 캡처 시작 → 뜨는 창에서 이 탭(현재 탭)을 선택
  3. 창 하단의 "탭 오디오도 공유"가 켜져 있는지 꼭 확인
  4. 촬영하는 동안 재생을 멈추지 마세요. 다른 탭의 소리를 쓰려면 링크 없이 바로 캡처 시작 → 그 탭 선택
PC의 크롬·엣지에서만 됩니다. 휴대폰 브라우저는 탭 소리 캡처를 지원하지 않습니다 — 휴대폰에서는 음악 파일을 내 음악으로 올려 주세요.
선택된 배경음악이 없습니다. 음악을 먼저 골라 주세요.

사용 방법

1 시작하기

크롬으로 https:// 주소를 열어 주세요. 다운로드 폴더의 HTML 파일을 직접 열면 브라우저가 카메라를 막습니다.

홈 화면에 앱으로 깔기 — 화면 위쪽 홈 화면에 앱으로 설치 버튼을 누르고 설치를 선택하세요. 주소창 없는 전체 화면으로 열려 촬영 화면이 더 넓어집니다.

버튼이 안 보이거나 설치가 안 될 때
① 카카오톡·인스타 안에서 열린 화면이면 설치가 안 됩니다. 오른쪽 위 ⋮ → 다른 브라우저로 열기 → Chrome 으로 먼저 옮기세요.
② 크롬에서 ⋮ → 설치 및 바로가기 만들기 → 설치(바로가기 말고)를 고릅니다.
③ 그래도 홈 화면에 안 생기면 삼성 런처가 막은 것입니다. 홈 화면 길게 누르기 → 설정 → "홈 화면에 앱 추가"(새 앱 자동 추가)를 켜고 다시 설치하거나, 앱스 화면(모든 앱)에서 Joo-JeoB 아이콘을 찾아 홈 화면으로 끌어다 놓으세요.

안내 로봇 — 오른쪽 아래의 작은 로봇을 누르면 화면을 짚어 가며 지금 할 일을 말풍선으로 알려 줍니다. 짚은 버튼을 직접 누르면 다음 설명으로 넘어가고, 「대신 누르기」를 누르면 로봇이 눌러 줍니다. 맨 위에서 데모 따라하기를 고르면 화면마다 이어서 처음부터 끝까지 안내하고, 실전 내가 만들기에서는 조용히 기다리다가 로봇을 누를 때만 지금 화면을 알려 줍니다.

2 프로필 만들기

회원가입으로 이름과 비밀번호를 정하면 설정과 작업 기록이 남아 다음에 이어서 쓸 수 있습니다. 이 계정은 이 폰 안에만 저장되고 서버로 가지 않습니다. 그냥 한번 써보려면 로그인 없이 사용을 누르세요.

3 음악 고르기

  • 내장 트랙 — 4개 중 하나 선택. 앱이 직접 만든 소리라 저작권 걱정이 없습니다
  • 내 음악 — 파일 앱의 MP3·M4A, 또는 영상 파일을 넣으면 소리만 뽑아 씁니다
  • 음원 검색 — 저작권 프리 곡을 검색해 바로 선택. 가장 간단합니다 (처음 한 번 Jamendo Client ID 저장)
  • 탭 소리 — 꼭 유튜브의 특정 곡이어야 할 때 (아래 순서)
유튜브 음악 담아오기
① 화면 위에서 아래로 두 번 내려 빠른 설정 열기
② 화면 녹화 타일이 없으면 → 오른쪽 위 연필 모양 버튼 → 아래 ‘사용 가능한 버튼’에서 화면 녹화를 위로 끌어 놓고 완료
③ 화면 녹화 탭 → 소리 선택창에서 반드시 미디어 소리 (마이크 아님) → 녹화 시작
④ 유튜브에서 곡 재생 → 다 흐르면 화면의 정지 버튼
⑤ 앱의 화면 녹화 영상 선택으로 그 영상을 고르면 소리만 추출됩니다
요령 — 녹화 전 방해 금지 켜기, 광고 끝난 뒤 시작, 유튜브 자동재생 끄기
※ 녹화는 2분 안쪽으로 짧게 — 길면 느리고 실패할 수 있습니다

4 촬영

카메라 켜기 → 권한 허용. 화면이 9:16 세로로 잘려 녹화됩니다.

내 목소리에서 살리기 / 빼기를 고릅니다. 기본은 빼기라 배경음악만 깔끔하게 들어갑니다.

  • 살리기 — 말소리·웃음소리가 배경음악과 함께 파일에 들어갑니다. 잡음 억제와 울림 제거가 켜지고, 내 목소리는 스피커로 나가지 않아 하울링이 생기지 않습니다. 가장 깨끗하게 하려면 이어폰을 끼거나 배경음악을 스피커로 듣기를 끄세요
  • 빼기 — 주변 소음·말소리가 하나도 안 들어갑니다. 녹화 중에도 누르면 그 순간부터 조용해집니다
이미 찍힌 부분의 목소리는 나중에 뺄 수 없습니다. 목소리는 촬영하는 순간 영상에 합쳐지기 때문입니다. 빼고 싶은 구간이 오기 전에 빼기를 누르세요.

후렴부터 시작하고 싶으면 BGM 시작 지점을 옮기세요. 녹화 중에는 이전·다음과 뒤로가기가 잠깁니다.

5 결과 확인

  • 배경음악이 영상에 포함 — 저장된 파일을 실제로 열어 확인한 결과입니다
  • 저장된 파일의 프레임 — 버튼·글씨가 영상에 안 섞였다는 증거
  • MP4 · H.264 + AAC 로 나오면 어느 기기에서든 그대로 재생됩니다

앞뒤를 다듬으려면 구간 자르기를 쓰세요. 자른 뒤에도 BGM은 그대로 남습니다.

5.5 자막 넣기

결과 화면의 자막 탭, 한 칸에 한 줄씩 적기만 하면 바로 영상에 올라갑니다. 버튼을 누를 필요도, 시간을 입력할 필요도 없습니다.

배치는 영상 전체에 고르게(기본)와 처음부터 이어서 중에 고르고, 넘어가는 속도만 슬라이더로 맞추면 됩니다. 아래 막대 그래프로 어디에 놓였는지 보이고, 막대를 누르면 그 지점으로 미리보기가 이동합니다. SRT·VTT 파일을 올리면 시간까지 그대로 들어옵니다.

꾸미기 탭에서 글자체 8종, 크기·색·테두리, 위치, 그리고 타자·팝·물결·노래방 같은 움직임 10종을 고릅니다. 미리보기 영상 위에 바로 반영됩니다.

마지막에 편집 적용해서 내보내기를 누르면 자막과 구간 자르기가 한 번에 처리돼 화질 손실이 한 번뿐입니다.

5.7 인트로 · 아웃트로

결과 화면의 인트로 탭. 영상 앞뒤로 3초씩 붙습니다. 앞만, 뒤만, 둘 다 — 각각 켜고 끌 수 있습니다.

  • 디자인 5종 — 풍선 파티 · 축하 폭죽 · 폴라로이드(내 영상의 한 장면) · 촬영 슬레이트 · 로봇 팻말. 3초가 끝나도 글자는 화면에 남습니다
  • 자동 문구 — 앱이 재미있는 문구를 하나 골라 줍니다. 다른 문구를 누르면 바뀝니다
  • 직접 쓰기 — 첫 줄이 큰 글씨, 둘째 줄이 작은 글씨입니다

아래 세로 미리보기에서 3초가 반복 재생되니, 고른 그대로 나오는지 보고 정하면 됩니다. 배경음악은 인트로부터 끊기지 않고 그대로 이어집니다.

6 보내기

공유해서 보내기를 누르면 카카오톡·메시지가 뜹니다. 다운로드를 고르면 내 파일 > Download 폴더에 저장됩니다.

배경음악이 파일 안에 합쳐져 있어 어디로 보내도 소리가 지워지지 않습니다.

! 잘 안 될 때

카메라가 안 켜져요 — 주소가 https 인지 확인. 크롬 ⋮ → 사이트 설정 → 카메라 → 허용
소리가 안 들어가요 — 화면 녹화할 때 미디어 소리를 골랐는지 확인하세요
녹화가 중간에 멈춰요 — 촬영 중 화면을 끄거나 다른 앱으로 나가지 마세요
영상 파일에서 소리 추출 실패 — 녹화가 무음이거나 파일이 너무 큽니다. 짧게 다시 녹화해 보세요

1 시작하기

사파리로 https:// 주소를 열어 주세요. 사파리가 MP4로 저장해 주기 때문에 결과 영상이 어디서든 바로 재생됩니다.

홈 화면에 앱으로 깔기 — 사파리 아래쪽 공유 버튼(네모에 위쪽 화살표) → 목록을 내려 홈 화면에 추가 → 추가. 아이콘이 생기고, 주소창 없는 전체 화면으로 열립니다.

"홈 화면에 추가"가 안 보일 때
크롬·카카오톡 안의 브라우저에는 그 메뉴가 없습니다. 반드시 사파리로 여세요. (카톡에서 열렸다면 오른쪽 아래 ⋯ → Safari로 열기)

안내 로봇 — 오른쪽 아래의 작은 로봇을 누르면 화면을 짚어 가며 지금 할 일을 말풍선으로 알려 줍니다. 짚은 버튼을 직접 누르면 다음 설명으로 넘어가고, 「대신 누르기」를 누르면 로봇이 눌러 줍니다. 맨 위에서 데모 따라하기를 고르면 화면마다 이어서 처음부터 끝까지 안내하고, 실전 내가 만들기에서는 조용히 기다리다가 로봇을 누를 때만 지금 화면을 알려 줍니다.

2 프로필 만들기

회원가입으로 이름과 비밀번호를 정하면 설정과 작업 기록이 남습니다. 이 계정은 이 아이폰 안에만 저장되고 서버로 가지 않습니다. 그냥 써보려면 로그인 없이 사용을 누르세요.

3 음악 고르기

  • 내장 트랙 — 4개 중 하나 선택. 앱이 직접 만든 소리라 저작권 걱정이 없습니다
  • 내 음악 — 파일 앱의 음악, 또는 사진 앱의 영상(소리만 추출)
  • 음원 검색 — 저작권 프리 곡을 검색해 바로 선택. 가장 간단합니다 (처음 한 번 Jamendo Client ID 저장)
  • 탭 소리 — 꼭 유튜브의 특정 곡이어야 할 때 (아래 순서)
유튜브 음악 담아오기
① 설정 → 제어 센터에서 화면 기록을 추가 (처음 한 번만)
② 오른쪽 위에서 아래로 쓸어 제어 센터를 열고 화면 기록(동그라미) 버튼 탭 → 3초 뒤 시작
③ 유튜브에서 곡 재생 → 다 흐르면 화면 위 빨간 시간 표시 탭 → 중단
④ 앱의 화면 녹화 영상 선택으로 사진 앱의 그 영상을 고르면 소리만 추출됩니다
요령 — 녹화 전 방해 금지 켜기, 광고 끝난 뒤 시작
※ 녹화는 2분 안쪽으로 짧게 — 길면 느리고 실패할 수 있습니다

4 촬영

카메라 켜기 → 권한 허용. 화면이 9:16 세로로 잘려 녹화됩니다.

내 목소리에서 살리기 / 빼기를 고릅니다. 기본은 빼기(배경음악만)입니다. 살리면 잡음 억제가 켜지고, 내 목소리는 스피커로 나가지 않아 울리지 않습니다. 녹화 중에도 빼기를 누르면 바로 조용해집니다.

이미 찍힌 부분의 목소리는 나중에 뺄 수 없습니다. 빼고 싶은 구간이 오기 전에 누르세요.

무음 스위치가 켜져 있으면 스피커로 BGM이 안 들릴 수 있습니다. 그래도 파일에는 들어가니, 들어갔는지는 결과 화면의 배경음악 포함 줄로 판단하세요.

촬영 중 화면이 잠기면 녹화가 끊깁니다. 설정 → 디스플레이 및 밝기 → 자동 잠금을 길게 두거나 저전력 모드를 꺼 두면 안정적입니다.

5 결과 확인

  • 배경음악이 영상에 포함 — 저장된 파일을 실제로 열어 확인한 결과입니다
  • 저장된 파일의 프레임 — 버튼·글씨가 영상에 안 섞였다는 증거
  • MP4 · H.264 + AAC — 사파리에서는 보통 이렇게 나옵니다

앞뒤를 다듬으려면 구간 자르기를 쓰세요. 자른 뒤에도 BGM은 그대로 남습니다.
